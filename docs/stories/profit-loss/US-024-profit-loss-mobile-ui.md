US-025 — Visualización mobile de profit/loss

Descripción
Implementar la vista mobile de rendimiento del portfolio.

User Story
Como usuario mobile, quiero visualizar el rendimiento de mi portfolio desde el teléfono.

Criterios de aceptación
- La app muestra P&L por posición.
- La app muestra P&L consolidado.
- La app muestra valor actual del portfolio.
- La app muestra fecha de última actualización.
- La app consume la API backend.
