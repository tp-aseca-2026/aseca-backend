US-026 — Validación de profit/loss

Descripción
Implementar pruebas para validar los cálculos de valorización y rendimiento.

User Story
Como equipo de desarrollo, queremos validar los cálculos de P&L para asegurar que el rendimiento del portfolio sea correcto.

Criterios de aceptación
- Existen tests unitarios de cálculo de P&L.
- Existen tests de integración con precios persistidos.
- Se testean posiciones con ganancia.
- Se testean posiciones con pérdida.
- Se testea ausencia de precio actualizado.
- Existe al menos un flujo E2E de visualización de P&L.
