US-024 — Visualización web de profit/loss

Descripción
Implementar la vista web de rendimiento del portfolio.

User Story
Como usuario web, quiero visualizar el rendimiento de mi portfolio para evaluar mis inversiones desde el navegador.

Criterios de aceptación
- La web muestra P&L por posición.
- La web muestra P&L consolidado.
- La web muestra el valor actual del portfolio.
- La web muestra fecha y hora de última actualización de precios.
- La información proviene de la API backend.
