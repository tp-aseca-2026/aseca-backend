US-023 — Cálculo de profit/loss consolidado

Descripción
Implementar el cálculo de ganancia o pérdida total del portfolio.

User Story
Como inversor, quiero ver la ganancia o pérdida total de mi portfolio para evaluar el resultado general de mis inversiones.

Criterios de aceptación
- Se calcula P&L consolidado.
- Se calcula el valor total invertido.
- Se calcula el valor actual total.
- Se muestra rendimiento total absoluto.
- Se muestra rendimiento total porcentual.
