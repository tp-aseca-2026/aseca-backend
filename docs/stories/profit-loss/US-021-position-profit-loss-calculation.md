US-022 — Cálculo de profit/loss por posición

Descripción
Implementar el cálculo de ganancia o pérdida individual por posición.

User Story
Como inversor, quiero ver la ganancia o pérdida de cada posición para entender el rendimiento de cada inversión.

Criterios de aceptación
- Se calcula P&L por posición.
- Se compara precio de compra contra último precio almacenado.
- Se muestra resultado absoluto.
- Se muestra resultado porcentual.
- El cálculo es consistente con las transacciones registradas.
