US-005 — Validación de autenticación

Descripción
Implementar pruebas sobre el flujo de autenticación.

User Story
Como equipo de desarrollo, queremos validar el registro y login para asegurar que el acceso al sistema funcione correctamente.

Criterios de aceptación
- Existen tests unitarios para reglas de autenticación. 
- Existen tests de integración para registro y login. 
- Se testean credenciales válidas e inválidas. 
- Se valida que las rutas protegidas no sean accesibles sin autenticación. 
- Existe al menos un test E2E del flujo de login.
