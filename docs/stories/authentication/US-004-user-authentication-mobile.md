US-004 — Registro e inicio de sesión en mobile

Descripción
Implementar el flujo mobile de registro e inicio de sesión.

User Story
Como usuario, quiero registrarme e iniciar sesión desde la aplicación mobile para acceder a mi información desde el teléfono.

Criterios de aceptación
- Existe una pantalla mobile de registro. 
- Existe una pantalla mobile de login. 
- La aplicación valida los datos ingresados. 
- Se muestran errores de autenticación. 
- La app mobile consume la API real de autenticación. 
- Luego del login exitoso, el usuario accede a la aplicación mobile.
