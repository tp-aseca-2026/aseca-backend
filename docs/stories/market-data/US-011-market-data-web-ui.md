US-011 — Visualización web de datos financieros

Descripción
Implementar la interfaz web para búsqueda de empresas y visualización de datos financieros.

User Story
Como usuario web, quiero buscar empresas y ver su información financiera para analizar oportunidades de inversión.

Criterios de aceptación
- La web permite buscar por ticker o nombre.
- Se muestran resultados relevantes.
- Se muestran métricas financieras principales.
- Se muestra evolución histórica.
- Se muestran filings recientes.
- La web consume la API interna del backend.
