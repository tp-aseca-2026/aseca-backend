US-006 — Integración con SEC EDGAR para búsqueda de empresas

Descripción
Implementar la integración backend con SEC EDGAR para buscar empresas por nombre o ticker.

User Story
Como inversor, quiero buscar empresas por nombre o ticker para encontrar compañías sobre las que consultar información financiera.

Criterios de aceptación
- El sistema permite buscar empresas por ticker.
- El sistema permite buscar empresas por nombre.
- Los resultados provienen de EDGAR.
- Se muestra información básica de la empresa encontrada.
- El sistema maneja errores de la API externa.
- El sistema respeta las restricciones de consumo de EDGAR.
