US-007 — Consulta de métricas financieras desde EDGAR

Descripción
Implementar la consulta de métricas financieras principales desde la API XBRL Company Facts de EDGAR.

User Story
Como inversor, quiero consultar métricas financieras oficiales de una empresa para analizar su situación económica.

Criterios de aceptación
- Se pueden consultar métricas financieras por empresa. 
- Se muestran Revenue, Net Income, EPS, Total Assets y Total Liabilities. 
- Los datos provienen de EDGAR. 
- El sistema maneja empresas sin datos disponibles. 
- El sistema responde con un formato consistente para web y mobile.
