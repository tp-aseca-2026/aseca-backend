US-012 — Visualización mobile de datos financieros

Descripcion
Implementar la interfaz mobile para búsqueda de empresas y visualización de datos financieros.

User Story
Como usuario mobile, quiero buscar empresas y ver su información financiera desde el teléfono.

Criterios de aceptación
- La app mobile permite buscar por ticker o nombre.
- Se muestran métricas principales.
- Se muestran filings recientes.
- Se muestra evolución histórica.
- La app consume la API interna del backend.
