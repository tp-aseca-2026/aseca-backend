US-033 — Stress y load testing del API

Descripción
Implementar pruebas de carga y stress sobre la API utilizando Locust.

User Story
Como equipo de desarrollo, queremos validar el comportamiento del sistema bajo carga para identificar límites operativos y asegurar estabilidad.

Criterios de aceptación
- Existen pruebas de load testing con Locust.
- Existen pruebas de stress testing con Locust.
- Se documentan workflows seleccionados.
- Se justifica el dimensionamiento de carga.
- Se contempla el rate limit de EDGAR.
- Se documentan resultados y conclusiones.
