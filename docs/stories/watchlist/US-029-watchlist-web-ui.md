US-030 — Gestión de watchlist en web

Descripción
Implementar la interfaz web para administrar watchlist y comparar empresas.

User Story
Como usuario web, quiero administrar mi watchlist desde el navegador para seguir y comparar empresas fácilmente.

Criterios de aceptación
- La web permite agregar empresas.
- La web permite eliminar empresas.
- La web muestra la lista actual.
- La web permite comparar empresas guardadas.
- La web consume la API backend.
