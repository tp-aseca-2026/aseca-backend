US-031 — Gestión de watchlist en mobile

Descripción
Implementar la interfaz mobile para administrar watchlist y comparar empresas.

User Story
Como usuario mobile, quiero administrar mi watchlist desde el teléfono para seguir empresas de interés.

Criterios de aceptación
- La app permite agregar empresas.
- La app permite eliminar empresas.
- La app muestra la watchlist actual.
- La app permite comparar empresas.
- La app consume la API backend.
