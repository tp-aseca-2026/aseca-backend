US-032 — Validación de watchlist

Descripción
Implementar pruebas para validar gestión y comparación de watchlist.

User Story
Como equipo de desarrollo, queremos validar la watchlist para asegurar que las empresas se agreguen, eliminen y comparen correctamente.

Criterios de aceptación
- Existen tests de integración para agregar empresas. 
- Existen tests de integración para eliminar empresas. 
- Se testea que no se permitan duplicados. 
- Se testea comparación de métricas. 
- Existe al menos un flujo E2E de gestión de watchlist.
