US-029 — Comparación de métricas financieras entre empresas

Descripción
Implementar la comparación de métricas financieras entre empresas guardadas en watchlist.

User Story
Como usuario, quiero comparar métricas financieras entre empresas de mi watchlist para evaluar oportunidades de inversión.

Criterios de aceptación
- El usuario puede seleccionar empresas de su watchlist.
- Se comparan métricas principales.
- Los datos provienen de EDGAR.
- La comparación muestra valores de forma clara.
- El sistema maneja empresas sin datos disponibles.
