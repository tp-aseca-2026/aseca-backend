US-018 — Gestión de portfolio en web

Descripción
Implementar la interfaz web para compra, venta y visualización de posiciones.

User Story
Como usuario web, quiero gestionar mi portfolio desde el navegador para registrar operaciones y visualizar mis posiciones.

Criterios de aceptación
- La web muestra posiciones actuales.
- La web permite registrar compras.
- La web permite registrar ventas.
- La web permite consultar el historial de transacciones.
- La web muestra errores de validación.
- La web consume la API real del backend.
