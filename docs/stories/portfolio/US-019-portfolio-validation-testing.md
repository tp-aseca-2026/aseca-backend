US-020 — Validación de gestión de portfolio

Descripción
Implementar pruebas unitarias, de integración y E2E del flujo de portfolio.

User Story
Como equipo de desarrollo, queremos validar las operaciones de portfolio para asegurar que compras, ventas y posiciones se calculen correctamente.

Criterios de aceptación
- Existen tests unitarios de reglas de compra y venta.
- Existen tests de integración de APIs de portfolio.
- Se testea que no se pueda vender más de lo disponible.
- Se testea que las operaciones impacten en posiciones.
- Existe al menos un flujo E2E de compra y venta.
