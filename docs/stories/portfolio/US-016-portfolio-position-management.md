US-016 — Modificación y eliminación de posiciones

Descripción
Implementar APIs para modificar o eliminar posiciones del portfolio.

User Story
Como inversor, quiero modificar o eliminar posiciones para corregir o administrar mi portfolio.

Criterios de aceptación
- El usuario puede modificar una posición existente.
- El usuario puede eliminar una posición existente.
- Solo se pueden modificar o eliminar posiciones propias.
- Se validan cantidades y datos obligatorios.
- Los cambios impactan en la visualización del portfolio.
