US-014 — Compra de acciones

Descripción
Implementar la funcionalidad backend para registrar compras de acciones.

User Story
Como inversor, quiero registrar compras de acciones para incorporar posiciones a mi portfolio.

Criterios de aceptación
- El usuario puede comprar acciones válidas.
- La compra se registra con ticker, cantidad, fecha y precio vigente almacenado.
- La operación genera una transacción.
- La posición del portfolio se actualiza.
- No se aceptan cantidades inválidas.
- No se permite operar sobre tickers inexistentes.
