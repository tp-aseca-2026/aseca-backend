US-017 — Historial de transacciones

Descripción
Implementar la consulta del historial de operaciones del usuario.

User Story
Como inversor, quiero consultar mi historial de transacciones para revisar mis compras y ventas realizadas.

Criterios de aceptación
- El usuario puede ver sus compras realizadas.
- El usuario puede ver sus ventas realizadas.
- Las transacciones muestran ticker, cantidad, precio, fecha y tipo de operación.
- El historial se muestra ordenado por fecha.
- El usuario solo accede a sus propias transacciones.
