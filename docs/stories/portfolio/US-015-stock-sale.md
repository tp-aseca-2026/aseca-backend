US-015 — Venta de acciones

Descripción
Implementar la funcionalidad backend para registrar ventas de acciones.

User Story
Como inversor, quiero registrar ventas de acciones para reflejar la reducción o cierre de posiciones en mi portfolio.

Criterios de aceptación
- El usuario puede vender acciones que posee.
- No se puede vender más cantidad que la disponible.
- La venta se registra con precio vigente almacenado.
- La operación genera una transacción.
- La posición del portfolio se actualiza.
- Si la cantidad queda en cero, la posición queda cerrada o eliminada según diseño definido.
