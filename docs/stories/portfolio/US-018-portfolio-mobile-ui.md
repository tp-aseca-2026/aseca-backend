US-019 — Gestión de portfolio en mobile

Descripción
Implementar la interfaz mobile para compra, venta y visualización de posiciones.

User Story
Como usuario mobile, quiero gestionar mi portfolio desde el teléfono para operar y consultar mis posiciones.

Criterios de aceptación
- La app muestra posiciones actuales.
- La app permite registrar compras.
- La app permite registrar ventas.
- La app permite consultar historial.
- La app consume la API real del backend.
