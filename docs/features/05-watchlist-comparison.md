Feature 5 — Watchlist y comparación

Descripción
Permite guardar empresas de interés y compararlas financieramente sin necesidad de tener posiciones abiertas.

User story
Como usuario, quiero guardar empresas y compararlas para evaluar oportunidades de inversión.

Criterios de aceptación
- Se pueden agregar empresas a watchlist.
- Se pueden eliminar empresas de watchlist.
- No se permiten duplicados.
- Se pueden comparar métricas entre empresas guardadas.
