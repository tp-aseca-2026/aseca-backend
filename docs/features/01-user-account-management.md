Feature 1 — Gestión de cuenta de usuario

Descripción
Permite al usuario crear su cuenta personal e iniciar sesión para acceder de forma segura a su portfolio, watchlist y consultas financieras desde cualquier dispositivo.

User Story
Como usuario, quiero crear una cuenta e iniciar sesión para acceder y gestionar mi información personal de inversiones.

Criterios de aceptación
- El usuario puede registrarse con email y password.
- No pueden existir cuentas duplicadas.
- El usuario puede iniciar sesión con credenciales válidas.
- El sistema rechaza credenciales inválidas.
- La sesión funciona tanto en web como en mobile.
