Feature 4 — Análisis de rendimiento (Profit & Loss)

Descripción
Permite visualizar el rendimiento del portfolio en base a los últimos precios almacenados por el sistema.

User story
Como inversor, quiero visualizar mis ganancias o pérdidas para evaluar el rendimiento de mis inversiones.

Criterios de aceptación
- Se muestra profit/loss por posición.
- Se muestra profit/loss consolidado del portfolio.
- El cálculo utiliza precios persistidos.
- Se informa fecha de última actualización.
